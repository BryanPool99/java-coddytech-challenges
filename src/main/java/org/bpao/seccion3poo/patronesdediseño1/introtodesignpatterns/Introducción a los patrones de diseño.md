# Introducción a los patrones de diseño

Los patrones de diseño son soluciones comprobadas para problemas comunes en el desarrollo de software. Son esquemas que describen cómo estructurar clases y objetos para resolver tipos específicos de problemas.

Los patrones de diseño se dividen en tres categorías principales:

| Categoría | Propósito | Ejemplos |
| :--- | :--- | :--- |
| **Creacionales** | Cómo se crean los objetos | Singleton, Factory, Builder |
| **Estructurales** | Cómo se componen los objetos | Adapter, Decorator, Composite |
| **Comportamiento** | Cómo se comunican los objetos | Observer, Strategy, Command |

Los patrones de diseño proporcionan un vocabulario compartido entre los desarrolladores y ayudan a escribir código más flexible y fácil de mantener al aplicar principios como «programar para una interfaz, no para una implementación».
